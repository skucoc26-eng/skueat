# 관리자 화면 접근과 최고 관리자 2단계 인증

1. 직접 구현. 메인 화면의 운영자 링크와 GET /admin에 기존 DB 권한 확인을 적용한다. 비로그인/일반 회원/권한 회수된 운영자 → 메뉴 없음, /admin 404. 유효한 운영자와 최고 관리자 → 메뉴 표시, /admin 200. 일반 회원의 음식점 검색과 카카오 로그인은 그대로 동작한다.
2. 직접 구현. GET /admin/login은 최고 관리자 전용 로그인 양식으로 분리한다. POST /api/admin/login은 기존 CSRF, Origin, IP 제한과 비밀번호에 TOTP 6자리를 요구한다. 검증 설정 누락 또는 오류는 503, 패스워드만/틀린 코드/재사용은 401, 유효한 비밀번호와 새 코드는 200. 현재 및 직전 30초 구간을 허용한다. 마지막 사용 구간을 SQLite에 기록하고 관리자 세션 발급과 함께 커밋한다. 코드가 재사용되거나 저장이 실패하면 세션을 발급하지 않는다. 설정 활성화 및 인증 키 교체 전에 발급한 최고 관리자 세션은 무효화한다.
3. 직접 연결. 로그인 성공 → /admin 이동, 로그아웃 또는 권한 상실 → 홈으로 이동. 카카오 운영자는 공개 사이트에서 카카오 로그인 후 설정의 운영자 관리 메뉴를 사용한다. 관리 API의 기존 역할 검사를 유지한다.
4. 직접 검증. 기존 코드에서 방어 테스트 실패 재현 → 변경 후 회귀, RFC 6238 알려진 시간/코드, SQLite 재사용 차단, Go 전체/JS 전체/빌드 확인. Fly 배포 전 인증 앱 등록용 설정 키를 로컬 사용자 전용 파일에 준비하고 서버 Secret으로 설정한다. 운영에서는 /admin 404, /admin/login 200, 비밀번호만으로는 거절, 올바른 인증으로 관리자 화면과 API를 열 수 있는지 확인한다.
